# Changelog

## [0.1.0]

- Next meeting and countdown in the menu bar, shown within a configurable threshold.
- Today's meetings in a native dropdown, with per-event details, copy link and open in Calendar.
- One-click join for Zoom, Google Meet and Microsoft Teams. Right-click the status item or use a global hotkey.
- Calendar sources from macOS Calendar (EventKit), with per-calendar selection.
- Settings: countdown threshold, max title length, hide meeting title for screen sharing, launch at login, hotkey recorder.
- Automatic updates via Sparkle.
